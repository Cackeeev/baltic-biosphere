# Биосфера Балтики — независимый лендинг

Портфолио-концепт в поддержку помощи диким животным Калининградской области.

Статический HTML/CSS. GitHub Pages: Deploy from a branch → main → / (root).

Фотографии животных: https://balticbiosphere.ru/, CC BY-SA 3.0. Фотографии пейзажей и логотип предоставлены автором проекта. Иллюстрация тюленя создана с помощью ImageGen. Сайт не является официальным сайтом организации и не принимает платежи: ссылки направляют в её существующие каналы.
